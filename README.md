# 🚂🍾 ПЯТИЛИТРУХА БАГБИРА

**Рейс №67: Земля → Альфа-Центавра.**

Сурдин и научпопный советский алкаш едут в купе советского электропоезда к тройной
системе Альфа-Центавры. Двигатель — на багбире. Пятилитруха — одна.
Вопрос рейса один: **ХВАТИТ ЛИ?**

Игра на чистом HTML + CSS + ES-модулях: **без сборки, без зависимостей, без node_modules.**
Просто статика — значит, бесплатно хостится на GitHub Pages, Netlify, Vercel или
открывается двойным щелчком (нужен локальный сервер, см. ниже).

---

## Что внутри

Микс трёх жанров:

* **FTL-подобное управление ресурсами** — багбир, топливо, градус, вменяемость, тепло, КГБ-метр.
* **Карточки-события в духе Reigns** — 32 события, у каждого 2–3 выбора, часть открывается за «ризз».
* **Аркадные мини-игры в перегоне** — 4 штуки: тряска пятилитрухи, ритм «67», удержание уровня, скроллер вагона.

Плюс: живая сцена на canvas (звёздное небо, качающийся вагон, пятилитруха с настоящим
уровнем жидкости и пузырьками), процедурный стук колёс через Web Audio, мемные тосты,
телеприёмник «Радиоточка», хроника рейса и 5 финальных званий — от «МЛАДШИЙ ЛАБОРАНТ
КОСМОСА» до «АКАДЕМИК СУРДИН».

### Правила за минуту

| Ресурс | Что делает |
|---|---|
| 🍾 **Багбир** | топливо для печки и двигателя, выпивка и смысл рейса. Кончился — рейс встал |
| 🌡️ **Градус** | добавляет ходу, но злит проводницу. Падает сам, поднимается выпивкой |
| 🧠 **Вменяемость** | не дай себе стать слишком трезвым: 0 = выпить всё сразу |
| 🔥 **Тепло** | держится, пока в баке есть топливо. Кончилось топливо — вагон выстывает |
| 🕵️ **КГБ-метр** | 100 = высадят на 67-м разъезде |
| ⛽ **Бак** | 0,38 л на перегон. Заливается багбиром |
| ✨ **Ризз** | открывает лучшие варианты выборов |

Нужно пройти **24 перегона** и набрать **4,10 светового года** до станции «АЛЬФА-ЦЕНТАВРА».

### Управление

| Клавиша | Действие |
|---|---|
| `1`…`6` | хлебнуть 41 г / выпить 250 г / залить в бак 0,5 л / тряхнуть бутыль / почитать Сурдина / поспать |
| `Ж` | едем дальше (обычный перегон) |
| `Ф` | полный ход (−2,5 л багбира, −6 вменяемости, +1,0 к ходу) |
| `И` | дрейф на инерции (экономия багбира и нервов) |
| `ПРОБЕЛ` / ЛКМ / тап | в мини-играх: жать и держать |
| `←` `→` | в скроллере вести вагон |
| `R` | новый рейс |

## Запуск локально

ES-модули не грузятся с `file://`, поэтому нужен любой статический сервер из корня проекта:

```powershell
# вариант 1: Python (обычно уже есть)
python -m http.server 8777
# открыть http://127.0.0.1:8777/

# вариант 2: Node
npx --yes serve -l 8777 .
```

## Деплой на GitHub Pages

### Вариант A — автоматически (в репозитории уже лежит workflow)

1. Создай репозиторий и запушь этот проект в ветку `main`:

   ```powershell
   git init
   git add .
   git commit -m "Пятилитруха багбира: первый рейс"
   git branch -M main
   git remote add origin https://github.com/<ТВО_ИМЯ>/<РЕПО>.git
   git push -u origin main
   ```

2. На GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Всё. Workflow `.github/workflows/pages.yml` сам соберёт статику в `_site`
   (index.html, styles.css, src/, assets/) и опубликует её.
4. Адрес будет вида `https://<ТВО_ИМЯ>.github.io/<РЕПО>/`.
   Все пути внутри игры относительные, поэтому подкаталог ей не мешает.

### Вариант B — вручную, без Actions

**Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.**
Ничего собирать не нужно: игра уже статика.

## Структура проекта

```
index.html            разметка интерфейса (HUD, сцена, карточки, правая панель)
styles.css            всё оформление: CRT-скан-линии, панели, адаптив под мобильные
src/main.js           контроллер: состояние UI, ходы, экраны, горячие клавиши
src/game.js           ядро: ресурсы, экономика хода, выбор событий, финалы, ранги
src/events.js         32 события рейса + байки для тикера + мемные тосты
src/render.js         canvas: звёзды, вагон, Сурдин и Вася, пятилитруха, мини-игры
src/minigames.js      логика мини-игр и оверлей
src/audio.js          процедурный стук колёс, гул вагона и 13 сэмплов из assets/
assets/               рабочие ассеты: картинки (img-*) и звуки (sfx-*, music-*)
raw-assets/           исходники от автора проекта «как были» (в сборку не попадают)
tools/smoke.mjs       headless-прогон 400 рейсов: баланс и целостность событий
tools/runtime-test.mjs рантайм-тест на заглушках DOM+Canvas: рендер и мини-игры
tools/check-dom.mjs   проверка, что все селекторы из JS есть в index.html
.github/workflows/pages.yml  автодеплой на GitHub Pages
```

## Тесты

```powershell
node tools/smoke.mjs          # 400 рейсов разными стратегиями + валидация всех событий
node tools/runtime-test.mjs   # прогон настоящего кода на заглушках DOM и Canvas
node tools/check-dom.mjs      # селекторы JS против index.html
```

`smoke.mjs` печатает винрейт, причины поражений и распределение финальных званий.
Текущий баланс при игре «как придётся»: **~72% побед**, средний финиш на 20-м ходу
из 24. Стратегия «экономить и никуда не спешить» проигрывает по времени — топливо
в бак надо заливать, иначе вагон не доедет.

## Ассеты

Исходники лежат в `raw-assets/` как были, а рабочие копии — в `assets/`
с нормализованными именами (их и подключает игра). Как они используются:

| Файл | Роль в игре |
|---|---|
| `img-portrait-a.jpg` | портрет Сурдина (левая карточка экипажа) |
| `img-portrait-b.jpg` | портрет Васи (правая карточка экипажа) |
| `img-m26/m27/m28/m29.jpg`, `img-photo43/46.jpg`, `img-boto-1/2/3.webp`, `img-channels.jpg` | мемная лента на титульном и финальном экране |
| `sfx-*.mp3` | 13 звуковых эффектов: ризз, «67», вдох, бейс, воздушка, пук, вой, бросок, крак, дзинь, галактика, «bruh», «fah» |
| `sfx-horn.ogg` | гудок электропоезда (CC0) — звучит при прибытии на станцию |
| `music-space.ogg` | фоновый космический эмбиент рейса (CC0) |
| `music-soviet.ogg` | ретро-марш на финальном экране (CC0) |

Портреты подключаются в `src/main.js` в объекте `FACES` — поменять персонажа можно
одной строкой. Мемная лента — массив `MEME_STRIP` там же.

Музыка: длинные треки играют как фоновые петли — `music-space.ogg` в рейсе,
`music-soviet.ogg` на экране победы, `sfx-hd.mp3`/`sfx-galaxy.mp3` как мемные вставки.

## Лицензии на ассеты

**Картинки и мемные звуки** добавлены автором проекта и используются как шутка
в некоммерческом фан-проекте. Если планируешь публиковать игру широко — проверь
права на исходники и замени сомнительные: достаточно положить свой файл в
`assets/` с тем же именем.

**Музыка и гудок — CC0 (Public Domain Dedication).** Атрибуция не требуется,
но указываем для порядка:

| Файл | Трек | Автор | Источник |
|---|---|---|---|
| `music-space.ogg` | «Out There» (space background loop) | yd | [OpenGameArt](https://opengameart.org/content/space-music-out-there) · CC0 1.0 |
| `music-soviet.ogg` | «March of The Preobrazhensky Regiment (NES Remix)» | Spring Spring | [OpenGameArt](https://opengameart.org/content/march-of-the-preobrazhensky-regiment-nes-remix) · CC0 1.0 |
| `sfx-horn.ogg` | «The horn of a Bluebird railcar» | NIRVAAN222222 | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:The_horn_of_a_bluebird_railcar.ogg) · CC0 1.0 |

Процедурный стук колёс и гул вагона генерируются кодом (Web Audio) — файлов не требуют.
