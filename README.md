# 🚂🍾 ПЯТИЛИТРУХА БАГБИРА

**Рейс №67: Земля → Альфа-Центавра.**

Сурдин и научпопный советский алкаш едут в купе советского электропоезда к тройной
системе Альфа-Центавры. Двигатель — на багбире. Пятилитруха — одна.
Вопрос рейса один: **ХВАТИТ ЛИ?**

Игра на чистом HTML + CSS + ES-модулях: **без сборки, без зависимостей, без node_modules.**
Просто статика — бесплатно хостится на GitHub Pages и открывается двойным щелчком
(нужен локальный сервер, см. ниже).

---

## Как это играется

Экран простой: **сцена → ресурсы одной строкой → история → действия → лог.**
Всё остальное (все приборы, бригада, инвентарь, хроника) спрятано в кнопку
**«▾ подробности»**, чтобы не выглядеть пультом космического корабля.

1. Сверху падает **событие** с 2–4 вариантами. Читаешь и выбираешь.
2. Между событиями жмёшь **действия**: хлебнуть 41 г, выпить 250 г, залить в бак,
   **ТРЯХНУТЬ БУТЫЛЬ**, почитать Сурдина, поспать.
3. Потом **🚂 ЕДЕМ ДАЛЬШЕ** — поезд идёт, багбир уходит, случается новое событие.
4. Иногда в перегоне выпадает **мини-игра** — тап/держи, всё объясняется одной строкой на экране.

### 🌀 Бредометр

Главная шутка механики: **чем больше пьёшь, тем менее надёжен рассказчик.**

| Бредометр | Состояние | Что происходит |
|---|---|---|
| 0–20 | ТРЕЗВ | описания сухие и научные |
| 20–45 | НАВЕСЕЛЕ | «колёса стучат словами» |
| 45–70 | КОСОЙ | текст событий подменяется на бредовый, в вагоне кто-то лишний |
| 70–88 | УЖРАВШИЙСЯ | за окном стоит женщина. Она не мигает |
| 88–100 | БЕЛОЧКА | инопланетянка реальна, интерфейс подрагивает, в тексте всплывают «помехи» |

Бредометр растёт от выпивки и сам по себе держится на градусе, а падает от сна и дрейфа.
Он же открывает **особые варианты выбора** — в том числе те, что ведут к ней.

### 💙 Инопланетная линия

При бредометре 36+ за окном появляется **она** — синяя, держится за поручень, которого нет.
Дальше всё зависит от тебя: помахать, налить ей через стекло, впустить в купе, провести ночь,
сговориться на Альфе. Это не отдельный режим, а цепочка из **4 событий с продолжением**
(`alien_window → alien_tambur → alien_night → alien_fiancee`), и у неё есть свой финал:

> **ХВАТИЛО НА ДВОИХ** (ранг S+) — если доехать вместе с ней.

Реплики, выборы и тексты написаны так, чтобы оставаться на уровне мема «дайте мне инопланетянку»,
а не превращаться в то, о чём нельзя говорить на лекции.

### Ресурсы

| Ресурс | Что делает |
|---|---|
| 🍾 **Багбир** | топливо, выпивка и смысл рейса. Кончился — рейс встал |
| 🌡️ **Градус** | даёт ход, кормит бредометр, злит проводницу |
| 🧠 **Вменяемость** | 0 = слишком трезв, выпил всё сразу |
| 🌀 **Бредометр** | правит рассказчиком и открывает странное |
| 🔥 **Тепло** | держится, пока в баке есть топливо |
| ⛽ **Бак** | 0,38 л на перегон, заливается багбиром |
| ✨ **Ризз** | открывает лучшие варианты выборов |
| 🕵️ **КГБ-метр** | 100 — высадят на 67-м разъезде |
| 💙 **Она** | насколько она тобой заинтересовалась |

Нужно пройти **24 перегона** и набрать **4,10 светового года** до станции «АЛЬФА-ЦЕНТАВРА».
Проигрыш: кончился багбир · стал слишком трезв · КГБ-метр 100 · замёрз · не успел по времени.

### 🎮 Мини-игры

Все управляются одинаково — **тап**, **удержание** или **тап по половине экрана**,
без клавиатуры и без ловли мелких зон. Логика в `src/minigames.js`, отрисовка в `src/render.js`.
Мини-игра открывается модальным окном по центру.

| Мини-игра | Что делать | Что даёт |
|---|---|---|
| **ТРЯСКА ПЯТИЛИТРУХИ** | тапай по бутылке как можно быстрее (22 тапа = идеально) | до +1,6 л багбира |
| **РИТМ «67»** | тапай, когда ромб подходит к метке | до +1,2 к ходу |
| **РАЗЛИТЬ ПО СТАКАНАМ** | держи и отпусти ровно на линии; пролил — потерял | до +1,0 л и +6 вменяемости |
| **СИНХРОН С НЕЙ** | тапай, когда обе метки совпали | до +16 к «она» и +8 ризза |
| **СТЫКОВКА НА РАЗЪЕЗДЕ** 🚀 | простенький космосим: тап в верхней половине — вверх, в нижней — вниз. Введи вагон в кольцо стыковки и удерживай курс, пока полоска не заполнится. Нужно 3 стыковки | до +0,8 к ходу и +5 л топлива |

У стыковки есть топливо, инерция, аварии и счётчик серии — как на старых аркадных автоматах.
Если холст почему-то не смог отрисоваться, мини-игра сама переключается в текстовый режим,
а не показывает чёрный экран.

### Управление

| Клавиша | Действие |
|---|---|
| `1`…`6` | действия хода |
| `Ж` | едем дальше · `Ф` — полный ход · `И` — дрейф |
| `ЛКМ` / тап | выборы и мини-игры |
| `R` | новый рейс · `Esc` — закрыть подробности |

## Запуск локально

ES-модули не грузятся с `file://`, поэтому нужен сервер из корня проекта.
Лучше всего — **свой сервер без кэша**: браузер агрессивно кэширует ES-модули,
и после правки `src/*.js` страница может остаться на старом коде.

```powershell
npm start                     # node tools/dev-server.mjs → http://127.0.0.1:8777/
npm start 8790                # другой порт (если 8777 занят старым процессом)

# альтернатива, если Node не хочется:
python -m http.server 8777    # но тогда после правок жми Ctrl+F5
```

`tools/dev-server.mjs` отдаёт всё с заголовком `Cache-Control: no-store`,
поэтому обычного F5 достаточно.

### Если что-то выглядит странно (пустой холст, зависшая игра)

**Сначала посмотри на метку сборки** в правом верхнем углу — там всегда написано
`сборка vN`. Если пусто или `сборка …`, значит JavaScript не загрузился: смотри консоль (F12).
В окне мини-игры заголовок тоже подписан сборкой.

Если сборка свежая, а с интерфейсом беда — смотри таблицу ниже: почти все
эти поломки уже случались и теперь закрыты тестами.

| Симптом | Причина | Чем закрыто |
|---|---|---|
| Окно мини-игры висит всегда, пустое | авторский `display` перебивал атрибут `hidden` | правило `[hidden]{display:none !important}`, проверяется в `check-dom.mjs` |
| Холст мини-игры чёрный, хотя игра идёт | мини-игра рисовалась на холст **сцены**, а холст мини-игры оставался дефолтным 300×150 | `_syncCanvas()` задаёт реальные размеры в device-пикселях; тест «рисуется на СВОЁМ холсте» |
| Кнопки выбора не видны / обрезаны | высоты секций на CSS Grid схлопывались | flex-раскладка с явными высотами, `check-dom.mjs` запрещает `grid-template-rows` у `#app` |
| Мини-игра зависает навсегда | исключение вне `try` прерывало `requestAnimationFrame` | весь кадр в `try/catch` + текстовый режим со спасением |
| Падение в момент стыковки | код звал несуществующий `sfx.ding()` | тест сверяет все вызовы `sfx.*` со списком существующих |

Про кэш, если всё-таки подозреваешь его:

1. Нажми **Ctrl+F5**. Если не помогло — открой игру на **другом порту**
   (`npm start 8790`): у другого порта свой кэш, он гарантированно пустой.
2. Сверь сборку с диском: `curl http://127.0.0.1:8790/__build`.
3. Если 8777 занят старым зависшим процессом, а прав его убить нет — просто возьми другой порт.

## Деплой на GitHub Pages

### Вариант A — автоматически (workflow уже в репозитории)

1. Создай репозиторий и запушь проект в ветку `main`:

   ```powershell
   git init
   git add .
   git commit -m "Пятилитруха багбира: рейс №67"
   git branch -M main
   git remote add origin https://github.com/<ТВО_ИМЯ>/<РЕПО>.git
   git push -u origin main
   ```

2. На GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` соберёт статику в `_site`
   (index.html, styles.css, src/, assets/) и опубликует её.
4. Адрес будет вида `https://<ТВО_ИМЯ>.github.io/<РЕПО>/`.
   Все пути внутри игры относительные, поэтому подкаталог ей не мешает.

### Вариант B — вручную, без Actions

**Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.**
Собирать нечего: игра уже статика.

## Тесты

```powershell
npm test                      # всё подряд
node tools/smoke.mjs          # баланс: 480 рейсов + отдельная погоня за инопланетной линией
node tools/runtime-test.mjs   # интерфейс, бредометр, 5 мини-игр, финальные экраны
node tools/check-dom.mjs      # селекторы и ассеты
```

Что проверяется (и почему это важно):

* **Мини-игры реально рисуются** — тест перехватывает вызовы canvas и требует
  минимум 12 графических операций и хотя бы одну надпись. Пустой чёрный холст провалит тест.
* **Все мини-игры доигрываются** — автоигрок играет настоящим вводом и должен получить
  минимум «хорошо».
* **Игра не зовёт несуществующие звуки** — список ключей `sfx` сверяется с вызовами в коде
  (эта проверка появилась после двух реальных падений на `sfx.ding`).
* **Варианты выбора всегда есть** для каждого события; при бредометре 90+ добавляются
  «бредовые» варианты.

Что показывают тесты сейчас:

* **~66% побед** при игре «как придётся», средний финиш на 19-м ходу из 24.
* Стратегия «экономить и никуда не спешить» проигрывает по времени: топливо в бак надо заливать.
* Стратегия «пить, чтобы стало интереснее» чаще попадает в КГБ, зато доводит бредометр
  до 100 и знакомит с ней.
* **Инопланетная линия:** знакомство случается в ~19% случайных рейсов,
  а при целенаправленной охоте за ней финал «ХВАТИЛО НА ДВОИХ» выпадает в **~40%** попыток.
* Все четыре мини-игры проверяются автоматически: тест «играет» в них настоящим вводом
  и требует оценку «идеально».

## Отладочный API

В браузере доступен `window.bagbier`:

```js
bagbier.newRun()        // новый рейс (можно с семенем)
bagbier.travel('leg')   // 'leg' | 'full' | 'drift'
bagbier.act('drink')    // действие хода
bagbier.choose(1)       // выбрать вариант события
bagbier.choices()       // список вариантов с доступностью
bagbier.mad()           // бредометр и его уровень
bagbier.narrative()     // что сейчас написано на экране
bagbier.state           // всё состояние рейса
bagbier.forceEnd(true)  // сразу показать финальный экран
```

## Лицензии

**Картинки и мемные звуки** добавлены автором проекта и используются как шутка
в некоммерческом фан-проекте. Если планируешь публиковать игру широко — проверь права
на исходники и замени сомнительные: достаточно положить свой файл в `assets/`
с тем же именем.

**Музыка и гудок — CC0 (Public Domain Dedication).** Атрибуция не требуется, но укажем:
